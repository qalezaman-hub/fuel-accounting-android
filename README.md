# Fuel Accounting Android

نسخه پایه پروژه اندرویدی حسابداری تیل‌فروشی.

## امکانات پایه
- خرید و تخلیه
- فروش و بارگیری
- موجودی جداگانه هرات/نیمروز و دیزل/پطرول
- رسید پول و تصفیه حساب
- حساب صرافی‌ها و تبدیل ارز
- گزارش روزمره
- کاربران و سطح دسترسی
- رابط فارسی و RTL
